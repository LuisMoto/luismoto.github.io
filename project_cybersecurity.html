Planteamiento del Problema

La detección automatizada de amenazas en texto no estructurado es un desafío debido a la variabilidad del lenguaje. Este proyecto construye una red neuronal capaz de clasificar correos electrónicos en tres categorías (Seguro, Phishing, Inyección SQL) procesando simultáneamente secuencias de palabras y características estructurales, alcanzando una precisión del 99.16%.

Muestreo y Data Augmentation

Se utilizó submuestreo (undersampling) para balancear el corpus a 11,340 muestras por clase. Al detectar un sesgo algorítmico que asociaba el idioma español con la clase "Segura", se aplicó Data Augmentation inyectando 1,200 muestras sintéticas de Phishing en español para equilibrar los pesos léxicos de la red.

Topología de la Red (Doble Entrada)

El diseño implementa una arquitectura híbrida en Keras que combina representaciones semánticas con extracción manual de características de dominio.

Rama NLP (Transformer)

Una capa de Embedding entrenada desde cero, conectada a un bloque de Multi-Head Attention, permite al modelo capturar el contexto semántico sin depender de modelos preentrenados que ignoran caracteres especiales.

Extracción y MaxPooling

Se reemplazó el AveragePooling por GlobalMaxPooling1D para evitar que ataques cortos de inyección SQL se diluyan matemáticamente dentro de textos conversacionales largos.

Regularización y Optimización

Entrenado con optimizador Adam y función de pérdida sparse categorical crossentropy. Se aplicaron capas Dropout (0.1 y 0.2), BatchNormalization y el callback de EarlyStopping para suprimir eficazmente el overfitting.

Análisis de Falsos Positivos

Al evaluar la inferencia, se detectó una fuerte correlación estadística aprendida hacia vocabulario como "urgente" o "password". Un ataque de Inyección SQL camuflado en un texto de soporte técnico intenso puede ser clasificado incorrectamente como Phishing, revelando el peso superior de la capa de atención sobre el Max Pooling en contextos específicos.

Conclusiones del Proyecto

El desarrollo del sistema evidenció la eficacia de una arquitectura de doble entrada para problemas complejos de ciberseguridad:

  • El uso estricto de callbacks evitó el memorizado de datos en las épocas avanzadas.
  • Las arquitecturas personalizadas son preferibles al Transfer Learning generalista cuando se requiere detectar sintaxis específica.
  • La inyección de datos sintéticos es una solución altamente efectiva para los sesgos iniciales de recolección.
